PUBLIC IMAGES
=============

How to add an image
1. Open the matching .txt file.
2. Copy everything under PROMPT.
3. Generate the image at the exact ASPECT RATIO and SIZE.
4. Save the PNG in the SAME folder, with the SAME name, but .png instead of .txt.

Example:
  public/images/home/hero.txt
  becomes
  public/images/home/hero.png

The website looks for the .png automatically. Until that file exists, the page shows a coloured placeholder.

Style for every image
- Educational, premium, modern science platform for Grade 8-12
- Not childish, not cartoon, not a textbook scan
- Afrikaans learners, but do NOT render any text, letters, watermarks or logos in the image
- Natural greens, navy blues, cream light, occasional teal / purple / orange
