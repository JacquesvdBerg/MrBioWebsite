# Life Sciences Educational Platform

Afrikaans Life Sciences learning platform for school learners, primarily covering Grades 8 to 12.

The site should not feel like a traditional school website or a boring textbook resource. The goal is to make Life Sciences more approachable, interactive and enjoyable while still being educational and useful for exam preparation.

The final website name/brand is still to be confirmed. Implementation should not assume the final name is "MnrBio".

---

## 1. Project Overview

The platform will combine:

- Educational content
- Free video lessons
- Paid notes / documents / resources
- Interactive learning activities
- Weekly Life Sciences facts
- Learner questions / live chat
- Community feedback
- An administration area to manage everything

## 5. Home Page

The home page acts as the central hub for the entire platform.

It should immediately communicate that learners can **learn, watch, play, explore and ask questions**.

The current concept of **Waarheen wil jy gaan?** works very well.

### Six main destinations

Requested by Oom Louis:

1. **Weekly Life Sciences Facts** — Random interesting Life Sciences information that changes regularly.
2. **Shop / Educational Material** — Learners or parents can browse documents, summaries, worksheets and other educational material available for purchase.
3. **Video Lessons** — Links to free syllabus-based video lessons covering Grades 8 through 12.
4. **Live Chat** — Learners can submit questions and communicate with the teacher.
5. **Comments & Suggestions** — Learners can suggest future topics, ask questions and provide feedback.
6. **Play & Learn** — Interactive educational games and activities.

The homepage can also display statistics such as:

- 40+ Video Lessons
- Grades 8–12
- 100% Afrikaans

## 14. Multiple Choice Quiz

Example:

*Which chamber pumps oxygenated blood around the body?*

- A. Right atrium
- B. Left ventricle
- C. Right ventricle
- D. Left atrium

- Incorrect answers
- Explanation

## 16. Word Search

## 17. Crossword

The teacher provides answers and clues.

Example:

- **Answer:** Mitochondria
- **Clue:** Organelle responsible for cellular respiration.

The site generates the crossword activity.

---

## 18. Match the Pairs

Examples:

- Platelets → Blood clotting

## 20. Diagram Activities

One of the strongest potential features.

The teacher uploads something such as a diagram of the heart.

The learner then needs to:

- Identify structures
- Click correct structures
- Drag labels onto the diagram
- Complete missing labels

Examples:

- Identify the Aorta.
- Drag "Left Ventricle" onto the correct area.

This could eventually become one of the platform's flagship features.

## 34. Technical Nature of the Project

Although it can look like a website from the outside, the requested functionality makes it closer to a web application / learning platform.

The combination of:

- Dynamic content
- Admin dashboard
- Interactive games
- Live chat
- Database
- Content management
- AI generation
- Comments / moderation
- Product enquiries

means it is more complicated than a basic informational website.

A standard simple WordPress website could cover some of the content pages, but implementing the full vision would likely require substantial plugins / custom development.

A custom web application provides much more flexibility for the interactive functionality.

## 37. Database Hosting

Originally the plan was to use a managed database platform.

That would handle things such as:

- Database
- Admin authentication
- Chat data
- Comments
- Product data
- Activity data
- Storage

The database could theoretically be self-hosted, but that adds considerably more infrastructure maintenance.

A managed service is generally simpler because backups, updates and much of the infrastructure are handled externally.

---

## 38. Running Costs

The project can initially be developed very cheaply.

Potential early costs include:

- **Website hosting** — potentially R0 if hosted through Okkert's infrastructure.
- **Database** — can potentially begin on a free development tier. If moved onto a production paid database plan, approximately ±R400/month, depending on exchange rate and provider pricing.
- **Email** — can initially be around R0/month at low volumes.
- **YouTube** — R0/month for video hosting.
- **AI** — usage based. For occasional weekly facts and content generation, likely only a small amount initially.
- **Domain** — existing domain may already be available, otherwise domain renewal is an annual cost.

---

## 39. Approximate Initial Monthly Infrastructure

During early development:

- Potentially close to **R0/month**

Once live and using a paid managed database:

- Approximately **R400–R500/month**

depending on database plan, AI usage and exchange rates.

This does not include developer fees or ongoing maintenance / support.
